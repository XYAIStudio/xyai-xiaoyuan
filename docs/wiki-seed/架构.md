# 架构

**English:** [[Architecture]] · 仓库文档：[docs/architecture.md](https://github.com/XYAIStudio/xyai-xiaoyuan/blob/main/docs/architecture.md)

**XYAI精灵小元** 是 **Tauri 2 + React 19 + Vite** 桌面伴侣。应用标识 `com.xyai.xiaoyuan`，版本 `0.1.0`。聊天 UI 不绑死某一个产品，而是通过 `BackendProvider` 连接 XYAIStudio 后端（FreeOS、openXYOS、本机 Grok Bot / XYAI Studio）。

## 目录

| 路径                        | 职责                                   |
| --------------------------- | -------------------------------------- |
| `src/windows/`              | 桌宠 / 对话 / 设置                     |
| `src/lib/providers/`        | 后端插件、注册表、HTTP                 |
| `src/lib/poseMachine.ts`    | 姿态状态机                             |
| `src/lib/mascots.ts`        | 16 官方造型                            |
| `scripts/mock-backends.mjs` | 本机模拟 FreeOS / openXYOS / Grok Bot  |
| `src-tauri/`                | 窗口、托盘、配置、钥匙串、快捷键、空闲 |

三个窗口标签：`pet`、`chat`、`settings`。浏览器预览用 `?window=`。

## BackendProvider

定义在 `src/lib/providers/types.ts`：

- `id`、`labelZh`、`labelEn`
- `ready`：没有远程对话 API 时必须 `false`，并给以「未就绪」开头的中文 `notReadyReason`
- `testConnection` / `listAgents` / `sendChat`（流式）
- 可选 `ensureThread` / `loadHistory`
- `secretKeys`、`defaultBaseUrl`

注册表顺序：`freeos` → `openxyos` → `xyai-studio`（未就绪 stub）→ `grokbot`。

HTTP 默认 15 秒超时。不要臆造尚未公开的路由。

## 如何新增 Provider

1. 阅读目标仓库的**公开**路由。若尚无远程对话 API，仍要注册并设 `ready: false`。
2. 把 `id` 加入 `PROVIDER_IDS`。
3. 新建 `src/lib/providers/<id>.ts`，推进 `BACKEND_PROVIDERS`。
4. 配置：专用 `AppConfig` 字段，或 `providerOptions[id]`。
5. 口令 / 令牌加入 `src-tauri/src/secrets_cmd.rs`。
6. 设置页增加表单。
7. 补 `providers.test.ts`。
8. 更新 [docs/backends.md](https://github.com/XYAIStudio/xyai-xiaoyuan/blob/main/docs/backends.md) 与 README 表格。

桌宠、托盘、16 表情与对话窗默认不用改。接口清单见 [[后端对接]]。
