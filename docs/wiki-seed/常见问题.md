# 常见问题

**相关页：** [[Home]] · [[快速开始]] · [[后端对接]] · [[Windows 安装包]]

## 没有 FreeOS / openXYOS 也能预览吗？

可以。运行 `npm run mock:backends`，把设置里的地址改成 `18088` / `13000` / `11340`。账号见 [[后端对接]]。

## 为什么 XYAI Studio 显示未就绪？

Studio 是本地优先 Electron 工作台，公开仓库还没有桌宠可调用的远程对话 API。提供方已经注册，避免以后再改 UI；连接测试会明确说明未就绪，不会假装能聊。

## Windows 安装包在哪下载？

目前没有公开下载。GitHub Releases 还是空的，`latest.json` 返回 404。CI 可以打出未发布的 Windows NSIS Artifact，但未登录打不开，不能当作下载入口。试用请克隆仓库后 `npm run tauri dev`。常规 CI **只打 NSIS**（`setup.exe`），不打 MSI。详见 [[Windows 安装包]]。

## 为什么没有 MSI？

WiX `light.exe` 曾在中文产品名路径（`XYAI精灵小元_…msi`）上失败。Windows 包使用 ASCII 产品名 `XYAI Xiaoyuan`，CI 以 NSIS 为准。需要 MSI 请在本机 Windows 上自行 `npx tauri build --bundles msi`。见 [docs/packaging-windows.md](https://github.com/XYAIStudio/xyai-xiaoyuan/blob/main/docs/packaging-windows.md)。

## 检查更新提示没有配置？

更新通道还没开通（`latest.json` 目前 404）。将来公开发布才需要仓库 Secrets：`TAURI_SIGNING_PRIVATE_KEY`（可选 `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`）。没有密钥不影响聊天，CI 仍可打未签名 NSIS。未签名安装包会触发 SmartScreen「未知发布者」。步骤见 [docs/signing.md](https://github.com/XYAIStudio/xyai-xiaoyuan/blob/main/docs/signing.md)。

## 怎样对接真实 FreeOS / openXYOS？

先启动后端，再 `npm run doctor` 看端口是否就绪，然后按 `npm run live` 的提示改设置。FreeOS 四步：[docs/live-freeos.md](https://github.com/XYAIStudio/xyai-xiaoyuan/blob/main/docs/live-freeos.md)。多后端：[docs/live-integration.md](https://github.com/XYAIStudio/xyai-xiaoyuan/blob/main/docs/live-integration.md)。

桌面联调是 **token-first**：复用已有 `access_token`（`GET /api/auth/me`），不要用空密码登录。连接成功但智能体不答，先到 FreeOS 配置该智能体的模型 / 供应商。见 [[后端对接]]。

## 屏幕理解会不会上传桌面？

不会。默认关闭。打开后只读本机窗口标题；「允许截屏分析」才拍缩小截图，且只在本机做启发式，不写磁盘、不上传。

## 浏览器里没有置顶桌宠？

`npm run dev` 只是 Vite 预览，没有 Tauri 透明窗、托盘和钥匙串。请用 `npm run tauri dev`。

## 密钥会进 Git 吗？

不会。发布构建走系统钥匙串；开发构建写本机 `dev-secrets.json`（勿提交）。

## 能不能提及其它桌宠项目？

不能。小元是 XYAI 自有形象，Issue / Wiki / 代码都不要写第三方桌宠名称。
