# 路线图

方向随 XYAIStudio 各独立产品的公开接口演进，不绑死单一后端。

## 近期

- 活动感知、音效脚手架、番茄钟与桌宠交互已落地；屏幕理解（截屏/OCR）保持关闭
- 保持 Windows **NSIS** 安装包 CI 绿色；需要时再评估 ASCII 文件名的本机 MSI
- 配置 `TAURI_SIGNING_PRIVATE_KEY` 后走 GitHub Releases 自动更新
- XYAI Studio 一旦暴露远程 listAgents / 对话 HTTP，把 `xyai-studio` 提供者从「未就绪」接成可用（在此之前保持 stub）
- 文档与 Wiki 同步（本页来自 `docs/wiki-seed/`）

## 中期

- 为组织内新的独立仓库增加 `BackendProvider`，桌宠 UI 不重写
- 模拟网关覆盖更多失败路径（超时、断线重连）
- 姿态：更多文案提示与夜间/离开策略，不新增非官方造型充数

## 不会做

- 不会改名成其它桌宠，也不会混用第三方形象
- 不会臆造尚未公开的后端 API
- 不会把私钥或用户口令写进仓库

讨论请到 <https://github.com/XYAIStudio/xyai-xiaoyuan/discussions>。
