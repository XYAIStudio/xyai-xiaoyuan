## 状态映射

| 状态        | 姿态                               |
| ----------- | ---------------------------------- |
| 待机 / 问候 | 挥手问好、拥抱欢迎（约 12 秒轮换） |
| 思考 / 流式 | 认真思考、灵感乍现                 |
| 忙碌 / 工具 | 快乐奔跑、太空探索                 |
| 成功        | 点赞鼓励、胜利跳跃                 |
| 感谢 / 亲近 | 比心                               |
| 创作 / 生成 | 魔法创造、小画家                   |
| 夜间 / 离开 | 晚安陪伴                           |

叠化约 380ms，16 张 PNG 启动时预加载。流式或拖动时暂停待机轮换。右键 / 设置点选会保持一段时间；勾选 **锁定姿态** 则完全冻结。发「谢谢小元」「画一张星空」可分别看到比心 / 创作。

细节与常量见仓库 [docs/poses.md](https://github.com/XYAIStudio/xyai-xiaoyuan/blob/main/docs/poses.md)。
