# 快速开始

需要 **Node.js LTS** 与 **Rust 1.88+**。仓库根目录 `rust-toolchain.toml` 钉死 `1.88.0`。系统依赖见 [Tauri 前置条件](https://tauri.app/start/prerequisites/)。

## 安装并启动桌面端

```bash
git clone https://github.com/XYAIStudio/xyai-xiaoyuan.git
cd xyai-xiaoyuan
npm install
npm run tauri dev
```

启动后：透明置顶桌宠、系统托盘、左键打开对话、右键选 16 表情。默认快捷键 `CmdOrCtrl+Shift+Y` 显示小元，`CmdOrCtrl+Shift+H` 打开当前后端主页。

## 浏览器预览（无透明置顶）

```bash
npm run dev
```

然后打开：

- 桌宠 <http://localhost:1420/?window=pet>
- 对话 <http://localhost:1420/?window=chat>
- 设置 <http://localhost:1420/?window=settings>

## 没有真实后端

```bash
npm run mock:backends
```

地址与账号见 [[后端对接]]。质量检查：`make check`。更完整的说明在仓库 [docs/getting-started.md](https://github.com/XYAIStudio/xyai-xiaoyuan/blob/main/docs/getting-started.md)。
