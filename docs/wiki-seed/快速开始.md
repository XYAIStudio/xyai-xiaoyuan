# 快速开始

**English:** [[Quick Start]] · 仓库文档：[docs/getting-started.md](https://github.com/XYAIStudio/xyai-xiaoyuan/blob/main/docs/getting-started.md)

需要 **Node.js LTS** 与 **Rust 1.88+**。仓库根目录 `rust-toolchain.toml` 钉死 `1.88.0`。系统依赖见 [Tauri 前置条件](https://tauri.app/start/prerequisites/)。

## 安装并启动桌面端

```bash
git clone https://github.com/XYAIStudio/xyai-xiaoyuan.git
cd xyai-xiaoyuan
npm install
npm run tauri dev
```

也可以 `make install` 再 `make dev`。首次会编译 Rust 侧。

启动后：透明置顶桌宠、系统托盘、单击轮换姿态、双击打开对话、右键选 16 表情 / 拍一拍 / 喂食 / 晚安。

| 快捷键              | 作用             |
| ------------------- | ---------------- |
| `CmdOrCtrl+Shift+Y` | 显示小元         |
| `CmdOrCtrl+Shift+H` | 打开当前后端主页 |
| `CmdOrCtrl+Shift+C` | 打开对话         |
| `CmdOrCtrl+Shift+T` | 切换点击穿透     |
| `CmdOrCtrl+Shift+P` | 番茄钟开始/结束  |
| `CmdOrCtrl+Shift+K` | 拍一拍           |

快捷键可在 **设置 → 快捷键** 修改。

## 浏览器预览（无透明置顶）

```bash
npm run dev
```

然后打开：

- 桌宠 <http://localhost:1420/?window=pet>
- 对话 <http://localhost:1420/?window=chat>
- 设置 <http://localhost:1420/?window=settings>

`npm run dev` 没有托盘、钥匙串和透明窗，请用 `npm run tauri dev` 跑真正的桌面伴侣。

## 没有真实后端

```bash
npm run mock:backends
```

地址与账号见 [[后端对接]]。

## 本机真实 FreeOS

优先 `http://127.0.0.1:8088`（`:3000` 未开可忽略）：

```bash
npm run doctor
npm run live:freeos
```

四步：doctor → 设置 → 测试连接 → 聊天。详见 [docs/live-freeos.md](https://github.com/XYAIStudio/xyai-xiaoyuan/blob/main/docs/live-freeos.md)。桌面联调是 **token-first**；智能体若无模型配置，聊天可能失败。见 [[后端对接]]。

质量检查：`make check`。下一步：[[后端对接]] · [[姿态与动画]] · [[Windows 安装包]] · [[架构]]。
