# 后端对接

**English:** [[Backends]] · 仓库文档：[docs/backends.md](https://github.com/XYAIStudio/xyai-xiaoyuan/blob/main/docs/backends.md)

在 **设置 → 后端** 选择提供者并填写配置。密钥写入系统钥匙串（开发构建写入本机 `dev-secrets.json`，切勿提交）。

| 后端               | 仓库                                                     | 默认地址                | 状态       | 设置字段                                 |
| ------------------ | -------------------------------------------------------- | ----------------------- | ---------- | ---------------------------------------- |
| FreeOS / XYAI      | [FreeOS](https://github.com/XYAIStudio/FreeOS)           | `http://127.0.0.1:8088` | 可用       | 地址、用户名、密码（已登录可复用 token） |
| openXYOS           | [openXYOS](https://github.com/XYAIStudio/openXYOS)       | `http://127.0.0.1:3000` | 可用       | API、邮箱、密码                          |
| XYAI Studio 工作台 | [xyai-studio](https://github.com/XYAIStudio/xyai-studio) | （无远程对话入口）      | **未就绪** | 可选探测地址                             |
| 本机 Grok Bot      | 本机网关                                                 | `http://127.0.0.1:1340` | 可用       | 地址、Bearer 令牌或 `gateway.json`       |

先启动对应产品，再点「测试连接」「保存」。本机联调**优先 FreeOS `http://127.0.0.1:8088`**（`:3000` 未开可忽略）。最短路径：[docs/live-freeos.md](https://github.com/XYAIStudio/xyai-xiaoyuan/blob/main/docs/live-freeos.md)。多后端探活：[docs/live-integration.md](https://github.com/XYAIStudio/xyai-xiaoyuan/blob/main/docs/live-integration.md)。

不要臆造端点。下列接口均来自各仓库当前公开路由。

## 桌面 token-first 联调（FreeOS）

本机桌面联调是 **token-first**，不是无密码登录：

1. 先启动 FreeOS（默认 `http://127.0.0.1:8088`），必要时在 FreeOS 桌面完成登录。
2. 小元 **设置 → 后端** 保持 FreeOS / `:8088`。
3. 优先复用钥匙串 `freeos_token`（对应 FreeOS WebView 的 `auth_token`）。`GET /api/auth/me` 通过即可测连接、列智能体。没有有效令牌时再 `POST /api/auth/login` `{username,password}`（首次接入）。空密码登录会 `AUTH_FAILED`，不是可用路径。
4. 对话走已公开的 WebSocket：`/api/agents/{agent_id}/chat/ws?token=`。打开后先 `subscribe`，再 `user_turn`（带 `session_key`）。

**智能体模型配置：** 连接成功不等于模型能答。若聊天报模型 / 供应商错误（例如「模型调用多次重试后仍失败」），到 **FreeOS** 为该智能体配置模型。这是 FreeOS 侧配置，不是小元新增的接口。

## 公开接口（不要臆造）

**FreeOS：** token-first（本机已登录可复用 `auth_token`）· 路由用字符串 `agent_id` · `GET /api/health` · `GET /api/setup/status` · `POST /api/auth/login` `{username,password}` → `{access_token}` · `GET /api/auth/me` · `GET /api/agents` · `POST /api/agents/{agent_id}/threads` → `{thread_id,session_key}` · history · WebSocket 先 `subscribe` 再 `user_turn`。若 `/threads` 返回 404，回退文档表里的 `/chat/sessions` 别名。

**openXYOS：** `GET /api/health` · `POST /api/auth/login`（邮箱）· chats / messages · `POST /api/assistant/chat`

**XYAI Studio：** 本地优先 Electron 工作台，公开仓库没有桌宠可调用的 listAgents / 对话 HTTP。现有互通是 Studio → openXYOS。设置里可见，连接测试会说明未就绪。

**Grok Bot：** `GET /health` · `POST /api/listAgents` · `POST /api/sendPrompt`。仅本机 / 隧道。
