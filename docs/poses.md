# 姿态与动画

小元有 **16 个官方造型**。源文件在 `assets/mascot/poses/`（中文文件名），界面使用 `public/mascots/` 下的英文文件名 PNG。设置与桌宠右键菜单均可点选。

实现：`src/lib/mascots.ts`（目录与预加载）、`src/lib/poseMachine.ts`（状态机）、`src/windows/PetWindow.tsx`（双层 CSS 叠化）。

## 生命周期 → 姿态池

对话生命周期（`PetLifecycle`）驱动自动表情：

| 状态                                               | 姿态池                                                         |
| -------------------------------------------------- | -------------------------------------------------------------- |
| 待机 `idle`                                        | 挥手问好、拥抱欢迎（约 12 秒温和轮换）；22:00–06:00 用晚安陪伴 |
| 问候 `welcome`                                     | 拥抱欢迎、挥手问好                                             |
| 连接 / 思考 / 出错 `connecting` `thinking` `error` | 认真思考、灵感乍现                                             |
| 流式输出 `streaming`                               | 认真思考、灵感乍现；超过约 2800ms 进入创作                     |
| 工具调用 `tool`                                    | 快乐奔跑、太空探索                                             |
| 成功 `success`                                     | 点赞鼓励、胜利跳跃                                             |
| 创作 `create`                                      | 魔法创造、小画家                                               |
| 感谢 `affection`                                   | 比心                                                           |
| 离开 `away`                                        | 晚安陪伴                                                       |

用户文案提示（`poseHintFromUserText`）：含「谢谢 / 感谢 / 比心」等会切到亲近；含「画一 / 创作 / generate」等会切到创作。

## 动画与锁定

常量（`src/lib/poseMachine.ts`）：

| 常量                  | 值    | 含义                                     |
| --------------------- | ----- | ---------------------------------------- |
| `POSE_CROSSFADE_MS`   | 380   | 叠化时长，避免透明窗黑闪                 |
| `IDLE_CYCLE_MS`       | 12000 | 待机轮换间隔                             |
| `MANUAL_HOLD_MS`      | 18000 | 手动点选后保持，直到下一次自动状态或超时 |
| `STREAM_TO_CREATE_MS` | 2800  | 长流式从思考过渡到创作                   |

行为要点：

- 启动时预加载全部 16 张 PNG，叠化过程不重新读盘。
- 双层图片：前景立即切到新姿态，背景旧图淡出。
- 流式输出、拖动桌宠、成功/出错展示期间暂停待机轮换。
- 右键或设置点选姿态会保持到下一次自动状态变化（或 18 秒）。
- 勾选 **锁定姿态**（`lockPose`）则完全冻结，直到取消锁定；锁定时仍可手动换造型。
- 设置里也可关闭 **根据对话状态自动切换表情**（`autoExpression`），此时回到默认待机姿势。
- **活动感知**、番茄钟、本地时钟会叠在同一套状态机上，但不会压过对话流式或锁定。详见 [活动感知与声音](activity-and-sound.md)。
- 单击轮换俏皮姿态，双击打开对话；悬停闪光，拖动轻晃。右键可「拍一拍 / 喂食 / 晚安」。连续喂食三次会庆祝「吃饱啦」。

相关测试：`src/lib/poseMachine.test.ts`、`src/lib/mascots.test.ts`、`src/lib/companion.test.ts`。
