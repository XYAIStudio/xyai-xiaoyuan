本目录只用于仓库展示与文档引用。应用运行时仍读取 [`assets/mascot/`](../mascot/) 与 [`public/mascots/`](../../public/mascots/)，请勿改那些路径。

- 静态造型：[`static/`](static/)（16 张 PNG，中文文件名）
